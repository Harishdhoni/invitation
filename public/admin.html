Connect Firebase first

The admin page saves to Firestore, so it needs your Firebase project details.

  1. Firebase console → Project settings → Your apps → add a Web app.
  2. Copy the firebaseConfig values into public/js/firebase-config.js.
  3. Reload this page.

Full steps are in SETUP.md.

            Hooks — how a template shows each event's details
            
The site fills these in for each event; leave out any you don't need. Full details are in TEMPLATES.md.

            
    
              
  • data-bind="names" (both names), name1, name2, initial1, initial2, title,
                tagline, dateLine, verse, help, hashtag.
    • 
              
  • Main date: day, month, mon, year, weekday, time, dateLong.
    • 
              
  • Photos: <img id="coverImg">, <img id="deityImg">.
    • 
              
  • Lists: a <template> inside #eventsGrid (fields name date time place venue desc icon number day mon year,
                data-href="map"), #wishesWall (message name), #coordinators (name phone phones, data-href="tel").
                data-if="field" hides an element when that field is empty.
    • 
              
  • Countdown #cdDays #cdHours #cdMins #cdSecs · wish form #wishForm #wishName #wishMessage ·
                intro #curtain-overlay opened by #openCurtainBtn or [data-open-invite] · .reveal gets .in on scroll ·
                language buttons .lang-btn[data-lang=en|ta].
    • 
              
  • Parts a link can hide: the sections #coupleCover #events #countdown #wishes #stay hide by themselves; mark anything else
                with data-part="cover|events|countdown|wishes|help|contacts|music|stay".
